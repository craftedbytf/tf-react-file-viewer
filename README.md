# React File Viewer (Crafted by TF)
View this library on npm - [@craftedbytf/react-file-viewer](https://www.npmjs.com/package/@craftedbytf/react-file-viewer)

## Introduction
This library serves as a wrapper around various file viewers, allowing you to display different types of files in your React applications. It supports a variety of file formats and provides extensibility for custom file types.

This is created as there is no actively maintained library that supports all file types in a simple way.

Use this library if you:
- ✅ need to display different types of files in your React application
- ✅ want an easy way to integrate file viewing capabilities
- ✅ need to customize file type rendering with your own components
- ✅ expect a rough and simple preview of files in your application

This library is not intended for:
- ❌ displaying a single file type -- *use the specific viewer directly*
- ❌ advanced file viewing features like annotations or editing -- *use a proprietary viewer library instead*
- ❌ high-fidelity rendering of complex file types -- *specify a custom renderer for high-quality rendering*

## Features
### Supported File Types
This library provides built-in support for the following file types:
- pdf
- docx

You can also add support for custom file types by providing a custom renderer. 
See the [Custom File Type Renderer](#custom-file-type-renderer) section below for more details.
